# 🚌 School Bus Boarding Tracker

A cute, mobile-first web app for tracking children boarding a school bus, built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- Live bus status banner (Phase 1 / Phase 2 / Left the community)
- Editable driver information card
- Phase 1 / Phase 2 tabs, each with independent boarding data
- Instant search per phase
- One-tap "Mark Present" with undo, success animation, and confetti when a phase is fully boarded
- Add / edit / move / delete students, with delete confirmation
- Boarded / Remaining / Total summary with progress bar, plus a cross-phase dashboard
- Everything persists to `localStorage`

## Getting started

```bash
npm install
npm run dev
```

## Tech stack

React · TypeScript · Vite · Tailwind CSS v4 · Radix UI primitives · Framer Motion · Lucide icons
